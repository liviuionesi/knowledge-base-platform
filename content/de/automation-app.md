# Evelyn

Die Installation der **Evelyn**-Anwendung auf einem Windows-PC ist sehr einfach, da wir bereits die Standalone-Version erstellt haben. Hier sind die Schritte:

## 1. Anwendung herunterladen
[Klicken Sie hier, um den Evelyn ZIP-Installer herunterzuladen](https://github.com/pehlivanu/last_z_automation/releases/latest/download/EvelynBot-Windows.zip).

## 2. "Installieren" (Entpacken)
1. Suchen Sie auf Ihrem Windows-PC die heruntergeladene ZIP-Datei.
2. Klicken Sie mit der rechten Maustaste darauf und wählen Sie **"Alle extrahieren..."**.
3. Wählen Sie einen Ordner (z. B. Ihren Desktop), um die Dateien zu speichern.

## 3. Telefon vorbereiten
1. Aktivieren Sie das **USB-Debugging** auf Ihrem Android-Telefon (Einstellungen > Entwickleroptionen).
2. Verbinden Sie das Telefon über ein USB-Kabel mit dem Windows-PC.
3. Wenn das Telefon fragt, klicken Sie auf **"USB-Debugging zulassen"**.

## 4. Anwendung ausführen
1. Öffnen Sie den extrahierten Ordner `EvelynBot-Windows`.
2. Suchen Sie die Datei namens `EvelynBot.exe` (sie hat das Evelyn-Helden-Symbol).
3. Doppelklicken Sie darauf, um zu starten!

### TIPP
Sie müssen Python oder etwas anderes nicht auf dem Windows-PC installieren. Die `EvelynBot.exe` enthält alles, was sie zum Ausführen benötigt.
