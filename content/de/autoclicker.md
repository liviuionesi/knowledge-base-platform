# AutoClicker Einrichtungs-Guide

Dieser Guide erklärt, wie man **AutoClicker - Automatic tap** installiert und konfiguriert, um das Drücken der "Hilfe"-Taste im Spiel zu automatisieren. Dies ist nützlich, um Ihre Allianz-Hilfe-Warteschlange ohne ständige manuelle Eingaben leer zu halten.

## 1. Die Anwendung installieren

1. Öffnen Sie den **Google Play Store**.
2. Suchen Sie nach **"AutoClicker - Automatic tap"**.
3. Installieren Sie die Anwendung.

## 2. Berechtigungen aktivieren

Wenn Sie AutoClicker zum ersten Mal öffnen, fragt es nach **Barrierefreiheitsservice**-Berechtigungen. Dies ist erforderlich, damit die App Tipps auf Ihrem Bildschirm simulieren kann.

1. Starten Sie **AutoClicker**.
2. Tippen Sie bei der Berechtigungsaufforderung auf **OK**.
3. Suchen Sie in den sich öffnenden Systemeinstellungen in der Liste der heruntergeladenen Dienste nach **Auto Clicker**.
4. Schalten Sie den Schalter auf **Ein**.
5. Bestätigen Sie durch Tippen auf **Zulassen**.

## 3. Konfiguration für Auto-Hilfe

Um einfach die "Hilfe"-Taste zu drücken, ist der **Einzel-Ziel-Modus** normalerweise ausreichend.

1. Kehren Sie zum Hauptbildschirm der AutoClicker-App zurück.
2. Tippen Sie unter **Einzel-Ziel-Modus** auf **Aktivieren**.
   - Eine schwebende Steuerleiste und ein blauer Zielkreis erscheinen auf Ihrem Bildschirm.
3. Öffnen Sie das Spiel.

## 4. Positionierung und Einstellungen

1. Navigieren Sie zu dem Bildschirm, auf dem die "Hilfe"-Taste erscheint (normalerweise das Hauptquartier oder der Weltbildschirm).
2. Ziehen Sie den **Blauen Zielkreis** und platzieren Sie ihn direkt über der Stelle, an der die "Hilfe"-Blase/Ikone erscheint.
   - *Tipp: Warten Sie, bis eine Hilfeanfrage erscheint, damit Sie ihn perfekt positionieren können.*
3. Tippen Sie auf das **Einstellungen (Zahnrad)**-Symbol auf der schwebenden Steuerleiste.
4. Setzen Sie das **Klick-Intervall** auf einen vernünftigen Wert (z. B. **34 Sekunden, 67 Sekunden**), um sicherzustellen, dass Hilfeanfragen schnell erfasst werden, das Gerät jedoch nicht verzögert, aber auch um die automatische Erkennung durch das Spiel zu verhindern, was ein Problem sein könnte. Ich weiß, dass dies in der Vergangenheit ein Problem bei Spielern war, die Autoclicker verwendeten, um Schätze zu erhalten.
5. Tippen Sie auf **Speichern**.

## 5. Automatisierung starten

1. Wann immer Sie das Drücken der Hilfe automatisieren möchten, tippen Sie auf die **Wiedergabe (Dreieck)**-Taste auf der schwebenden Steuerleiste.
2. Die App wird nun diesen Ort automatisch wiederholt anklicken.
3. Um zu stoppen, tippen Sie auf die **Pause**-Taste.

## Fehlerbehebung

- **Dienst stoppt:** Wenn Android den Hintergrunddienst beendet, müssen Sie ihn möglicherweise in der App wieder aktivieren.
- **Ziel bewegt sich:** Stellen Sie sicher, dass sich die Spieloberfläche nicht verschoben hat. Richten Sie das Ziel bei Bedarf neu aus.
