# Bienvenue sur <span className="text-orange">l'Alliance Phenix !</span>
Ceci est le site officiel de l'**Alliance Phenix** dans le jeu **Last Z: Survival Shooter**.

## Qu'est-ce que ce site web ?

Ce site web contient des **guides complets**, des **stratégies** et des informations pour aider les nouveaux comme les anciens membres à mieux jouer, atteindre les **objectifs de l'alliance** et, le plus important, <span className="text-orange">respecter nos règles</span>.

## Commencer

Naviguez à travers les sections en utilisant la barre latérale à gauche. Chaque section contient des informations détaillées sur différents aspects du jeu.

### Fonctionnalités clés

- **Base de données des héros** : Informations complètes sur tous les héros
- **Guide tactique** : Stratégies pour les événements comme Capital Clash
- **Conseils d'alliance** : Meilleures pratiques pour la collaboration

## Besoin d'aide ? Vous avez des suggestions ? Vous voulez participer ?

Si vous ne trouvez pas ce que vous cherchez, ou si vous avez des questions, envoyez un message privé à **-IronMaiden-** dans le jeu, la personne qui administre ce site web.
