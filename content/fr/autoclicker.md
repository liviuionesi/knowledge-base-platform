# Guide de Configuration AutoClicker

Ce guide explique comment installer et configurer **AutoClicker - Automatic tap** pour appuyer automatiquement sur le bouton "Aide" dans le jeu. C'est utile pour garder votre file d'attente d'aide d'alliance vide sans intervention manuelle constante.

## 1. Installer l'Application

1. Ouvrez le **Google Play Store**.
2. Recherchez **"AutoClicker - Automatic tap"**.
3. Installez l'application.

## 2. Activer les Permissions

Lorsque vous ouvrez AutoClicker pour la première fois, il demandera les permissions de **Service d'Accessibilité**. C'est nécessaire pour que l'application puisse simuler des clics sur votre écran.

1. Lancez **AutoClicker**.
2. Appuyez sur **OK** à l'invite de permission.
3. Dans les paramètres système qui s'ouvrent, trouvez **Auto Clicker** dans la liste des services téléchargés.
4. Basculez l'interrupteur sur **Activé**.
5. Confirmez en appuyant sur **Autoriser**.

## 3. Configuration pour l'Aide Auto

Pour simplement appuyer sur le bouton "Aide", le **Mode Cible Unique** est généralement suffisant.

1. Retournez à l'écran principal de l'application AutoClicker.
2. Sous **Mode Cible Unique**, appuyez sur **Activer**.
   - Une barre de contrôle flottante et un cercle cible bleu apparaîtront sur votre écran.
3. Ouvrez le jeu.

## 4. Positionnement et Paramètres

1. Naviguez vers l'écran où le bouton "Aide" apparaît (généralement le Quartier Général ou l'écran Monde).
2. Faites glisser le **Cercle Cible Bleu** et placez-le directement sur l'endroit où la bulle/icône "Aide" apparaît.
   - *Astuce : Attendez qu'une demande d'aide apparaisse pour pouvoir le positionner parfaitement.*
3. Appuyez sur l'icône **Paramètres (Engrenage)** sur la barre de contrôle flottante.
4. Réglez l'**Intervalle de clic** sur quelque chose de raisonnable (par ex. **34 secondes, 67 secondes**) pour vous assurer qu'il attrape rapidement les demandes d'aide mais ne ralentit pas l'appareil, mais empêche également la détection automatique par le jeu, ce qui pourrait être un problème. Je sais que c'était un problème par le passé avec les joueurs qui utilisaient des auto-cliqueurs pour obtenir les trésors.
5. Appuyez sur **Sauvegarder**.

## 5. Démarrer l'Automatisation

1. Chaque fois que vous voulez automatiser l'appui sur l'aide, appuyez sur le bouton **Lecture (Triangle)** sur la barre de contrôle flottante.
2. L'application va maintenant cliquer automatiquement sur cet emplacement de manière répétée.
3. Pour arrêter, appuyez sur le bouton **Pause**.

## Dépannage

- **Le Service s'arrête :** Si Android tue le service en arrière-plan, vous devrez peut-être le réactiver dans l'application.
- **La Cible Bouge :** Assurez-vous que l'interface du jeu n'a pas bougé. Réalignez la cible si nécessaire.
