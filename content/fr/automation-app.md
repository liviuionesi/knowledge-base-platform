# Evelyn

L'installation de l'application **Evelyn** sur un PC Windows est très simple car nous avons déjà construit la version autonome. Voici les étapes :

## 1. Télécharger l'application
[Cliquez ici pour télécharger l'installateur ZIP d'Evelyn](https://github.com/pehlivanu/last_z_automation/releases/download/latest/EvelynBot-Windows.zip).

## 2. "Installer" (Extraire)
1. Sur votre PC Windows, localisez le fichier ZIP téléchargé.
2. Faites un clic droit dessus et sélectionnez **"Extraire tout..."**.
3. Choisissez un dossier (comme votre bureau) pour enregistrer les fichiers.

## 3. Préparez votre téléphone
1. Activez le **débogage USB** sur votre téléphone Android (Paramètres > Options du développeur).
2. Connectez le téléphone au PC Windows avec un câble USB.
3. Si le téléphone le demande, cliquez sur **"Autoriser le débogage USB"**.

## 4. Exécuter l'application
1. Ouvrez le dossier `EvelynBot-Windows` extrait.
2. Trouvez le fichier nommé `EvelynBot.exe` (il aura l'icône de l'héroïne Evelyn).
3. Double-cliquez dessus pour commencer !

### CONSEIL
Vous n'avez pas besoin d'installer Python ou quoi que ce soit d'autre sur le PC Windows. Le `EvelynBot.exe` contient tout ce dont il a besoin pour fonctionner.
