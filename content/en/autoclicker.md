# AutoClicker Setup Guide

This guide explains how to install and configure **AutoClicker - Automatic tap** to automate pressing the "Help" button in the game. This is useful for keeping your alliance help queue clear without constant manual input.

## 1. Install the Application

1. Open the **Google Play Store**.
2. Search for **"AutoClicker - Automatic tap"**.
3. Install the application.

## 2. Enable Permissions

When you first open AutoClicker, it will ask for **Accessibility Service** permissions. This is required for the app to simulate taps on your screen.

1. Launch **AutoClicker**.
2. Tap **OK** on the permission prompt.
3. In the system settings that open, find **Auto Clicker** in the list of downloaded services.
4. Toggle the switch to **On**.
5. Confirm by tapping **Allow**.

## 3. Configuration for Auto-Help

For simply pressing the "Help" button, **Single Target Mode** is usually sufficient.

1. Return to the AutoClicker app main screen.
2. Under **Single Target Mode**, tap **Enable**.
   - A floating control bar and a blue target circle will appear on your screen.
3. Open the game.

## 4. Positioning and Settings

1. Navigate to the screen where the "Help" button appears (usually the Headquarters or World screen).
2. Drag the **Blue Target Circle** and place it directly over the location where the "Help" bubble/icon appears.
   - *Tip: Wait for a help request to appear so you can position it perfectly.*
3. Tap the **Settings (Gear)** icon on the floating control bar.
4. Set the **Click Interval** to something reasonable (e.g., **34 seconds, 67seconds**) to ensure it catches help requests quickly but doesn't lag the device, bit also prevents autodetection by the game, which might be a problem. I know that it was a problem in the past with players that used autoclikers to get the treasures.
5. Tap **Save**.

## 5. Starting Automation

1. Whenever you want to automate the help pressing, tap the **Play (Triangle)** button on the floating control bar.
2. The app will now automatically click that location repeatedly.
3. To stop, tap the **Pause** button.

## Troubleshooting

- **Service Stops:** If Android kills the background service, you may need to re-enable it in the app.
- **Target Moves:** Ensure the game UI hasn't shifted. Re-align the target if necessary.
