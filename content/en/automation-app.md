# Evelyn

Installing the **Evelyn** application on a Windows PC is very simple since we already built the standalone version. Here are the steps:

## 1. Download the application
[Click here to download the Evelyn ZIP installer](https://github.com/pehlivanu/last_z_automation/releases/download/latest/EvelynBot-Windows.zip).

## 2. "Install" (Extract)
1. On your Windows PC, locate the downloaded ZIP file.
2. Right-click it and select **"Extract All..."**.
3. Choose a folder (like your Desktop) to save the files.

## 3. Prepare your Phone
1. Enable **USB Debugging** on your Android phone (Settings > Developer Options).
2. Connect the phone to the Windows PC with a USB cable.
3. If the phone asks, click **"Allow USB Debugging"**.

## 4. Run the application
1. Open the extracted `EvelynBot-Windows` folder.
2. Find the file named `EvelynBot.exe` (it will have the hero Evelyn icon).
3. Double-click it to start!

### TIP
You do not need to install Python or anything else on the Windows PC. The `EvelynBot.exe` contains everything it needs to run.
