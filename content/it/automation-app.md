# Evelyn

L'installazione dell'applicazione **Evelyn** su un PC Windows è molto semplice poiché abbiamo già creato la versione standalone. Ecco i passaggi:

## 1. Scarica l'applicazione
[Fai clic qui per scaricare l'installer ZIP di Evelyn](/downloads/EvelynBot-Windows.zip).

## 2. "Installa" (Estrai)
1. Sul tuo PC Windows, individua il file ZIP scaricato.
2. Fai clic con il pulsante destro del mouse su di esso e seleziona **"Estrai tutto..."**.
3. Scegli una cartella (come il desktop) per salvare i file.

## 3. Prepara il tuo telefono
1. Abilita il **debug USB** sul tuo telefono Android (Impostazioni > Opzioni sviluppatore).
2. Collega il telefono al PC Windows con un cavo USB.
3. Se il telefono lo richiede, fai clic su **"Consenti debug USB"**.

## 4. Esegui l'applicazione
1. Apri la cartella `EvelynBot-Windows` estratta.
2. Trova il file denominato `EvelynBot.exe` (avrà l'icona dell'eroina Evelyn).
3. Fai doppio clic su di esso per iniziare!

### SUGGERIMENTO
Non è necessario installare Python o altro sul PC Windows. `EvelynBot.exe` contiene tutto il necessario per l'esecuzione.
